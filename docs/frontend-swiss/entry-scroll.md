# 合并入口与滚动动画验收

用户审核独立原生 HTML 案例后，授权接入正式项目。欢迎与菜单共用 ResearchEntryPage；根路由默认欢迎，workspace 默认菜单，会话内进入过菜单则根路由也定位菜单。后端、数据库和原有功能路由不变。保留接入前已有的菜单居中及研究表单改动。

## 动画机制

欢迎分区保持自然布局高度。滚动距离 S、欢迎高度 H 时，欢迎表面以顶部为原点应用 translateY(S) scaleY(1-S/H)。相对视口的顶部保持 0，底部与菜单顶部同时到达 H-S。上滑恢复；不劫持滚轮，不吸附，不调整布局高度。完全离屏时隐藏欢迎表面，暂停其波纹。

GSAP ScrollTrigger 在菜单每行顶边经过视口高度 85% 时切换 data-revealed。CSS 把编号、标签和箭头整体从 translateX(-10%) 归位（1s，cubic-bezier(.86,0,.07,1)）；87% 不透明的米白遮罩从右侧原点 scaleX(1) 到 0（1.2s，cubic-bezier(.645,.045,.355,1)），逐步从左到右显示黑色。分割线与点击范围保持固定。上滑反向展开遮罩，CSS 从当前状态衔接；停下滚动后时间动画继续播放。

临时灰色仅属于这项用户审核过的入口动画，是现有配色规则的明确例外。聚焦按钮即解除遮罩和横移。减少动态效果使用普通滚动、黑色文字及接近零时长的全局过渡设置。

NEXT 平滑滚到菜单；菜单 Research Agent 滚回欢迎。语言切换使用 scroll:false 和短期会话位置快照，避免再次套用默认菜单定位。菜单就位且滚动停下 120ms 后才启用 API Key 检查。查询期间只提供读屏状态，不打开短暂的加载弹窗，避免快速切换语言时焦点被抢走。确认缺少配置或查询失败后，overlay 门禁保留入口组件挂载；保存成功将焦点交回菜单标题且不滚动。默认 replace 门禁保留旧页面调用方式，功能目标路由仍受配置门禁保护。

Canvas 使用未压缩的布局尺寸，指针坐标根据实际显示矩形转换；观察欢迎分区可见性而不是压缩至零的 Canvas 表面。保持原来的噪声、弹簧、线场、DPR 上限和资源清理机制。
